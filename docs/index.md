# Добро пожаловать в Algobook

Этот проект посвящён алгоритмам. За небольшим исключением, я не являюсь автором размещённых здесь материалов, однако стремлюсь собрать, переработать и отформатировать как можно больше информации из открытых источников, чтобы представить её в наиболее удобном виде.

**Что вы найдёте здесь:**

- 📚 Подробные описания алгоритмов, разбитые по тематическим рубрикам
- 💻 Тщательно задокументированные примеры кода на Python

> ⚠️ Весь представленный код — это учебные примеры, демонстрирующие ключевые идеи. Они не претендуют на production-качество.
